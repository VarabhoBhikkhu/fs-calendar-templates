- vnc and starting up xfce in manjaro
	- The file `~/.vnc/xstartup` is an executable shell script that TigerVNC runs automatically when starting a display session. It sets up the environment variables and executes your desktop environment or window manager.
	- https://apt.izzysoft.de/packages/app.familygem
	  aqui es donde vamos ai
	- Here is the standard content for starting an **XFCE desktop**:
	  
	  ```
	  #!/bin/sh
	  
	  # Clear inherited session variables to avoid conflicts with host desktop sessions
	  unset SESSION_MANAGER
	  unset DBUS_SESSION_BUS_ADDRESS
	  
	  # Load desktop resource settings and keyboard mappings (if available)
	  [ -r $HOME/.Xresources ] && xrdb $HOME/.Xresources
	  xsetroot -solid grey
	  
	  # Launch the XFCE desktop environment
	  exec startxfce4
	  ```
	- ### Breakdown of Key Lines
	- **#!/bin/sh**: Tells the system to execute the file using the standard POSIX shell.
	- **`unset SESSION_MANAGER` / `unset DBUS_SESSION_BUS_ADDRESS`**: Prevents D-Bus and session manager conflicts, which is especially important inside containers (like Termux `proot-distro`) or remote servers.
	- **exec startxfce4**: Replaces the shell process with XFCE's startup manager. Using `exec` ensures that when you log out of XFCE, the VNC server process cleans up and terminates cleanly.
	- ### Making the Script Executable
	  
	  For TigerVNC to execute this script properly, it **must** have executable permissions:
	  
	  ```
	  chmod +x ~/.vnc/xstartup
	  ```
	  
	  To verify permissions were applied successfully, run `ls -l ~/.vnc/xstartup`. The output should start with `-rwxr-xr-x`.

	- como crear usuarios en manjaro #users #manjaro
		- You can create a user in Manjaro using either the graphical settings or the terminal.
		  
		  **Option 1: Graphical Interface (GUI)**
		- Open **System Settings** (KDE Plasma) or **Settings** (GNOME/XFCE).
		- Navigate to **Users** (or **User Manager**).
		- Unlock the panel by clicking **Unlock** / **Authenticate** and entering your admin password.
		- Click **Add New User** (or the **+** icon).
		- Fill in the **Full Name**, **Username**, and **Password**.
		- Select the account type:
			- **Standard:** For regular non-administrative access.
			- **Administrator:** To grant `sudo` privileges.
			  
			  **Option 2: Terminal (Command Line)**
			  
			  Open a terminal and run the following steps:
		- **Create the user account:**
		  
		  ```
		  sudo useradd -m -G wheel -s /bin/bash newusername
		  ```
			- `-m` creates a home directory (`/home/newusername`).
			- `-G wheel` grants administrative privileges via `sudo` (omit `-G wheel` for a standard user).
			- `-s /bin/bash` sets the default shell to Bash.
		- **Set a password for the new user:**
		  
		  ```
		  sudo passwd newusername
		  ```
		  
		  Enter and confirm the password when prompted.
		  
		  **Verify the User Creation**
		  
		  Check that the new home directory was created successfully:
		  
		  ```
		  ls -ld /home/newusername
		  ```
		  
		  *Verification:* If configured properly, the command returns directory permissions owned by `newusername`.

- installing oh my zsh power10k
	- Powerlevel10k is a fast and flexible theme for Zsh that provides custom segments for git status, command execution timing, and system status.
	- **Install Meslo Nerd Font**
	  *Prerequisite*
	  Powerlevel10k requires a patched Nerd Font to render icons, arrows, and glyphs correctly. Install the official font package from Manjaro's official repositories:
	  
	  ```
	  sudo pacman -S ttf-meslo-nerd-font-powerlevel10k
	  ```
	  
	  *Verification:* Open your terminal preferences (e.g., **XFCE Terminal** -> **Edit** -> **Preferences** -> **Appearance**) and ensure **MesloLGS NF** is selected as the font.
	- git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
	- **Set Theme in .zshrc**
	  *Configuration file*
		- Open your Zsh configuration file in a terminal text editor:
		  
		  ```
		  nano ~/.zshrc
		  ```
		- Find the `ZSH_THEME` line and change its value:
		  
		  ```
		  ZSH_THEME="powerlevel10k/powerlevel10k"
		  ```
		- Save and close the file (`Ctrl+O`, `Enter`, then `Ctrl+X`).
		  
		  *Verification:* Reload your shell configuration by running `source ~/.zshrc`.
	- **Run the Configuration Wizard**
	  *Interactive wizard*
	  The configuration wizard will launch automatically upon reloading `~/.zshrc`. If it does not start, launch it manually:
	  
	  ```
	  p10k configure
	  ```
	  
	  Follow the step-by-step prompts to test your glyph rendering (confirming icons like diamonds and locks render cleanly) and customize your prompt style (Rainbow, Lean, Classic, or Pure).
	  *Verification:* Completing the wizard creates `~/.p10k.zsh` and applies your chosen prompt style to the terminal immediately.
